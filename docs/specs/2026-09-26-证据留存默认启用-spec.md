# 证据留存默认启用规格

## 1. 背景

Agent 的复核结论依赖事件前后的视频片段和关键帧。若证据留存依赖部署者显式开启，
事件可能直接进入复核，Agent 只能依据检测元数据分析，无法稳定给出可追溯结论。

## 2. 目标

- 删除 agent.recording_evidence.enabled 配置接口。
- 删除 evidence_cache.enabled 配置接口。
- runner 始终创建短时证据缓存分支。
- Agent 事件链固定先创建取证任务，取证完成后再创建复核与索引任务。
- 默认可信证据目录为 /var/lib/ssv/evidence-cache。
- 保留缓存容量、保留时长、取证窗口、轮询、租约和重试参数的可配置能力。
- 旧配置继续携带任一 enabled 字段时明确报未知字段，避免静默忽略。

## 3. 配置契约

- agent.recording_evidence 只包含轮询、租约、重试和证据窗口参数。
- evidence_cache 只包含目录、分段时长、保留时长和容量参数。
- agent.evidence_roots 默认包含 /var/lib/ssv/evidence-cache。
- evidence_cache.directory 必须位于 agent.evidence_roots 的任一目录内。

## 4. 运行时契约

- EventConsumer 始终按 episode 生命周期登记事件。
- AgentService 始终创建 RecordingEvidenceWorker。
- 生产 ledger 始终创建 evidence_extract 任务；完成取证后再创建 review 与 index 任务。
- runner 始终建立 encoded tee 和 splitmuxsink 缓存分支。

## 5. 非本阶段范围

- 不改变证据片段和关键帧的数量、格式或时间窗口算法。
- 不改变证据缓存的目录、容量和保留时长默认值。
- 不迁移或改写历史设计文档。
