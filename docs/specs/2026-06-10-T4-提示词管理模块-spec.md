# T4 提示词管理模块 Spec

## 目标

将 Agent 复核相关提示词从硬编码文本收敛到 `agent/src/ssv_agent/prompts/`，为后续真实 LLM/VLM provider 接入提供可复用、可测试、可审计的 messages 组装能力。

本阶段不把 Python Agent 接入每帧同步检测链路；提示词模块只服务 Redis 事件消费后的异步复核流程。

## 范围

本阶段包含：

- 系统提示词 `DEFAULT_SYSTEM_PROMPT`，定义角色、判断原则、输出格式和行为约束。
- 四类复核策略模板：`direct_confirm`、`visual_review`、`rule_explain`、`notify_report`。
- few-shot 示例库和按标签检索能力。
- `PromptAssembler`，将 `ContextPack` 或兼容的 `ReviewContext` 组装为 messages 列表。
- `PromptLogger`，在真实 provider 调试时记录 prompt、response、模型名、耗时和截断信息。
- `PromptManager`，提供轻量健康检查和版本快照。

本阶段不包含：

- 真实 LLM/VLM API 调用。
- prompt 模板的数据库化或远程配置。
- 多模态图片 message 的正式组装；`assemble_vlm()` 仅保留接口。
- 基于真实业务数据的 few-shot 自动筛选。

## 模块边界

| 模块 | 职责 | 当前状态 |
|:--|:--|:--|
| `prompts/system.py` | 全局角色、判断原则、输出格式和约束 | 已实现 |
| `prompts/templates.py` | 四类策略模板和策略专属系统提示追加 | 已实现 |
| `prompts/examples.py` | few-shot 示例和标签检索 | 已实现 |
| `prompts/assembler.py` | `ContextPack` → messages，包含示例注入和预算截断 | 已实现 |
| `prompts/logger.py` | 记录 LLM 调用过程，mock 模式默认关闭 | 已实现 |
| `prompts/manager.py` | `validate()` 与 `get_versions()` | 已实现 |

## 数据流

```text
DetectionEvent
  → ContextEngine.collect()
  → ContextPack
  → PromptAssembler.assemble()
  → PromptAssembly.messages
  → M5 真实 provider 调用
```

M4 阶段 `AgentService` 已构造 `PromptAssembler` 和 `PromptLogger`，但 `StateMachine` 仍调用 `MockProvider.analyze(context)`。真实 provider 接入后再切换为 `provider.analyze_from_messages(assembly.messages)`。

## 约束

- 输出格式必须围绕 `is_violation`、`reasoning`、`needs_human`、`confidence`、`action_suggestion`、`summary`。
- 不确定时应设置 `needs_human=true`，不得伪造未提供的证据、规则或模型结论。
- 系统提示、模板、示例和日志结构必须可单元测试。
- prompt token 估算当前使用字符数/2 的近似方式；精确 tokenizer 不属于本阶段范围。
