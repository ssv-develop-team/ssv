# T2 YOLO 推理链路梳理 Plan

## 所属主线

本计划对应 `M1` 任务包 A，所属主线为 `T2` 感知算法与元数据。任务只新增中文文档，不修改跨主线接口。

## 实施步骤

1. 阅读 `docs/roadmap.md` 中 `M1` 任务包 A 的目标、输出和验收要求。
2. 阅读 `gst/ssv-infer/gstssvinfer.cpp`，按以下主题记录当前实现：
   - ONNX Runtime 初始化、Session 创建和输入输出 shape 识别。
   - `BGR` caps、视频帧 map、stride 和 frame id 处理。
   - letterbox 缩放、padding 和 `114 / 255` 填充值。
   - `RGB` 通道写入、`CHW` 布局和 `[1, 3, H, W]` 输入张量。
   - YOLOv8 输出解析、置信度过滤、类别过滤、坐标回映射和 NMS。
   - `mock-detect` 与 `async` 两条辅助路径。
3. 新增 `docs/specs/2026-06-04-T2-YOLO推理链路梳理-spec.md`，明确任务边界、当前接口、错误处理和验证方式。
4. 新增 `docs/yolo推理链路说明.md`，作为任务包 A 的主要交付文档。
5. 运行 `./ssv build`。
6. 运行 `meson test -C build`。
