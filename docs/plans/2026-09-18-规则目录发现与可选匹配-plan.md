## 实施约束

- 每一步只修改清单内文件，保留工作区中既有的 Episode、证据缓存、RTSP sink、overlay 和 Agent ledger 改动。
- 历史 spec/plan 不覆盖，只由本计划声明新设计替代旧的内联规则契约。
- 每一步完成后先检查差异和测试结果；按用户授权形成多个小提交，不推送、不创建 PR。
- 规则目录发现器是唯一目录遍历入口，避免 local 与 Qdrant 各自维护一套解析规则。
