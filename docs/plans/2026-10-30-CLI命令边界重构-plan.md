# CLI 命令边界重构计划

## 步骤 1：重构命令注册和实现模块

- 将 `redis` 命令模块改为 `infra`，将 `cache` 命令模块改为 `runtime`；重置必须由 `--yes` 显式确认。
- 将运行态动作 `clear` 改名为 `reset`。
- 将 Compose 服务函数 `start_redis/stop_redis` 改为 `start_infrastructure/stop_infrastructure`。
- 删除旧命令模块，确保解析器不再接受 `redis` 和 `cache`。

## 步骤 2：同步测试和文档

- 更新 CLI、Compose 和运行态命令测试。
- 更新 README、运行手册、Agent 运维手册和 roadmap 中的当前命令，并增加 `infra status`。
- 保留历史 spec/plan 中的旧命令记录。

## 步骤 3：验证

- 检查 `./ssv --help`、`./ssv infra --help` 和 `./ssv runtime --help`。
- 验证旧命令解析失败，新命令解析到正确 handler。
- 运行 CLI 与 Compose 相关 Python 测试。
- 检查 `git diff --check`，确认没有修改无关工作区文件。
