1. 停止本轮 Agent/Web/GST 与专用连续发布器，保持用户原有 MediaMTX 和 `/test` 发布器不变。
2. 用现有缓存清理命令只清空本项目 Redis Stream、去重记录和 EventLedger 运行表；重新核实 Redis RDB 状态。
3. 启动 Agent/Web 和实际 GST；观测事件后等待所需后窗，向 GST 发送受控停止请求并等待退出，不能再直接依赖固定三秒或硬杀。
4. 检查 MP4 可读、sidecar 完整、证据登记、复核及 Web DTO。外部模型若失败，单独报告真实错误，不归因于证据或以 mock 冒充成功。

冷启动首事件缺少前窗时，验证锚点图片的 HTTP 可读性和 `manual_review` 降级，不将其冒充完整自动复核。完整闭环另用隔离 RTSP 路径 `/ssv-validation`：原五秒片段前置八秒黑屏、后置十秒黑屏，为缓存前后窗留足覆盖；用户原 `/test` 和发布器保持不变。最终保留完整闭环的干净账本、事件证据及 `agent/outputs/validation-20261016/ssv.yaml`，专用回放器和临时输入在验证后删除。
